# Maxim Pharmacy

Modern, high-end website for Maxim Pharmacy — rebuilt from the client's existing demo content with a refined brand presentation.

## Run locally

```bash
cd maxim-pharmacy
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/about` — About
- `/shop` — Shop
- `/services` — Services
- `/contact` — Contact
- `/transfer` — Transfer a Prescription
- `/blog` — Blog

## Brand notes

Logo colors are preserved (red, blue, magenta accents) but simplified into a calm professional system: deep ink navy, medical blue, and refined crimson — avoiding the heavy Web 2.0 gradients of older pharmacy templates.
